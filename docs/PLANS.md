## 下一阶段入口

P2 当前目标是把已会签的产品蓝图转成产品原型，并为 UI 设计真源和技术架构准备输入。

P2 应输出：

- 产品原型。
- 用户原型会签标准。
- UI 设计真源输入要求。
- 技术前置清单。
- 技术风险和后续验证问题。

P2 不生成高保真 UI 设计稿，不冻结技术栈，也不冻结可执行里程碑。若 P2 中需要讨论版本路线，只能标记为高层假设。

P3 才输出：

- 版本路线图。
- V1/V2/Backlog 边界。
- 大里程碑计划。
- 小里程碑闭环清单。
- 小里程碑验收矩阵。
- 小里程碑依赖关系。

P3 必须重审 P1 蓝图中的 V1/V2/V3/Backlog 示例，不得直接冻结为最终版本路线。

P3 必须为成功指标补齐量化口径、阈值、样例和失败判定。
