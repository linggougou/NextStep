## 下一阶段入口

P2.1 已由用户会签通过。下一阶段明确进入 S3 UI 设计真源。

S3 应输出：

- 页面清单、页面目标、核心状态和关键交互。
- 组件状态表、响应式要求、空状态、错误状态和阻塞状态。
- 设计稿链接、截图证据和设计版本号。
- UI 验收清单。
- 不可偏离项。

S3 不做技术选型，不写技术架构，不拆版本路线、大里程碑或小里程碑，也不生成执行任务包。

S4 才输出：

- 技术目标。
- 候选技术栈与不选原因。
- 数据模型草案。
- 阶段门禁 / 状态机模型。
- AI 交互边界。
- 权限与数据安全。
- 风险验证计划。
- 回滚方案。

P3 才输出：

- 版本路线图。
- V1/V2/Backlog 边界。
- 大里程碑计划。
- 小里程碑闭环清单。
- 小里程碑验收矩阵。
- 小里程碑依赖关系。

P3 必须重审 P1 蓝图中的 V1/V2/V3/Backlog 示例，不得直接冻结为最终版本路线。

P3 必须为成功指标补齐量化口径、阈值、样例和失败判定。
