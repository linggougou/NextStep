# PRODUCT_SENSE

## 产品一句话

NextStep 是一个 AI 项目闭环落地系统，帮助用户把模糊想法整合成完整项目，再拆成多个可量化、可执行、可验收的小闭环，并持续推进直到交付。

## 核心用户

- 有目标但不知道如何拆解和推进项目的个人用户。
- 需要借助 AI 从想法走向交付的独立开发者、创业者、产品经理、内容创作者或小团队负责人。
- 已经会使用 AI，但经常遇到需求表达不完整、执行跑偏、项目范围漂移的人。

## 核心问题

- 用户的原始需求通常不是完整项目需求。
- AI 可以快速执行，但容易在需求不完整时沿错误方向推进。
- 只落地 MVP 不等于完整项目落地。
- 如果缺少阶段门禁、硬性指标和变更分流，项目会持续漂移。

## 产品原则

- 项目真源先于执行。
- 需求补全和冻结先于产品定义。
- 产品定义先于产品原型。
- 产品原型会签先于 UI 设计。
- UI 设计真源先于工程实现。
- 技术选型与架构先于里程碑实施。
- 完整项目蓝图先于版本拆分。
- 版本路线先于大里程碑。
- 大里程碑先于小里程碑。
- 小里程碑闭环先于 Agent 任务。
- 验收指标先于阶段切换。
- 变更分流先于需求并入。

## 当前非目标

- 不做单纯 Prompt 优化器。
- 不做 Agent 市场。
- 不做多 Agent 编排平台。
- 不做传统团队项目管理软件。
- 不做只有聊天记录、没有项目真源的 AI 助手。
- 不把 MVP 当成完整落地路线。
