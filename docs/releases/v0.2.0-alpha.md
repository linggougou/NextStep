# v0.2.0-alpha

## 定位

`v0.2.0-alpha` 是 NextStep 的本地、内部、开发者预览候选。它把已正式完成的 V1/V2 开发者内核固定为一个可本地打包、项目外临时安装并通过统一 `nextstep` 命令发现的检查点。package metadata 保持 `private: true` 与 `UNLICENSED`。

这不是 npm/公开发行、稳定 API、普通用户完整产品或 `full` 可信宿主；没有创建或授权 tag、push、upload、publish 或用户级 Skill 安装。CR-006 仍 open、qualified real runs=`0/3`，V3、V4、Final Acceptance 与 P5 均未完成。

## 范围

- 一个无 shell 的 `nextstep` dispatcher，向同包编译 CLI 透明传递参数、stdin/stdout/stderr 和退出状态。
- 13 个公开子命令：`status`、`requirement-intake`、`requirement-freeze`、`product-definition`、`interaction-prototype`、`carrier-decision`、`acceptance-profile`、`write-consistency`、`source-validate`、`version-chain`、`major-milestone`、`small-milestone`、`execution-packet`。
- 明确不打包内部 `contract-probe` 与 `project-value-validation` CLI。
- 仅打包公开 CLI 所需 adapters/domain JavaScript、v1 schemas、v2 product-definition schema、Skill/manifest、README、canonical quickstart 和本说明。

## 验证方式

候选必须通过：targeted Node tests、fresh `corepack pnpm check`、覆盖率不低于冻结门槛、真实 tgz allow/deny 审计、项目外 offline/ignore-scripts 临时安装，以及 version/help/version-chain/unknown/internal/trusted-capability smoke。版本号和本说明不能替代独立 package acceptance。

## 已知边界

- 自然语言整理依赖宿主 AI；内核只校验 RFC 8785/JCS 结构化候选。
- `requirement-freeze`、正式签认和 `write-consistency --commit` 等可信动作需要进程内 capability；直接 shell 调用继续 fail closed。
- CLI 安装与 Skill 注册相互独立，候选不会复制或覆盖用户级 Skill。
- fixture/headless/manual-isolated 证据不等于真实项目 `3/3` 或完整可信宿主。

## 回滚

停止使用并删除本任务在项目外创建的临时 consumer 与 tarball即可。若候选已被后续线性集成，则通过新的可审计提交回退该单一产品提交；不得使用 destructive Git 命令，也不得触碰用户级 Skill。
