## 4. Definition of Done

- S3 UI 设计真源格式明确。
- S4 技术架构文档格式明确。
- P3 版本与里程碑拆解格式明确。
- 后续验收报告格式明确。
- 每类格式都包含必填字段、合格标准和禁止提前写入内容。
- 本阶段不生成真实 UI、技术方案、版本路线、里程碑或验收结论。

## 5. 明确非目标

- 不生成高保真 UI 设计稿。
- 不选择或冻结技术栈。
- 不定义 V1 / V2 / Backlog 的真实边界。
- 不拆真实大里程碑或小里程碑。
- 不生成真实验收报告。
- 不写代码。

## 6. 阶段出口

用户确认 `docs/product-specs/005-stage-document-contracts.md` 可以作为后续真源文档格式约束后，才能进入 S3 UI 设计真源或其他后续阶段。

- P2 计划归档检查。
