## 4. Definition of Done

- 产品原型覆盖核心页面、主流程、关键交互和不可偏离项。
- 用户原型会签标准明确。
- UI 设计真源输入要求明确。
- 技术前置清单明确，包括待选技术项、架构风险、依赖和回滚关注点。
- P2 不冻结版本路线、大里程碑和小里程碑。

## 5. 明确非目标

- 不做高保真 UI 设计稿。
- 不冻结技术栈。
- 不写代码。
- 不拆可执行小里程碑。
- 不进入 P3 版本与里程碑拆解。
