# 主对话 Agent 编排需求上下文摘要

- 当前路线：`Skill 主载体 + 文档真源承载 + Web 暂不进入主路线`。
- 当前阶段：`S3 Skill 交互真源`。
- 新需求：Codex 主对话 Agent 持续引导和编排；开发、评估、测试等由其他 Agent 执行；主对话上下文保持聚焦。

## 2026-07-13 设计裁决

- 用户已确认总体架构：`三层职责 + 扁平调度 + 独立任务隔离 + 项目真源通信`。
- 三层为主对话 Agent、集成 Agent、执行 Agent 的逻辑职责；Codex 中不依赖三级递归 Agent。
- 主对话只负责沟通、决策与扁平调度，不读取或修改项目文件。
- 修改型任务使用独立 Codex task/worktree；测试、评估、审查默认只读。
- 主对话默认只接收集成 Agent 的一次阶段摘要；普通执行通知、日志、代码差异、测试输出和完整对话不进入主对话。
- 只有阻塞、验收失败、路线或范围变化、不可逆操作、安全风险、显著成本或用户主动要求时才按需展开。
- 后台任务活动期间可见；完成并集成成功后自动归档；主列表保留主对话、活动任务和阻塞任务。
- 核心目标是持续落地项目并保护主对话语义稳定性与用户心流，不以节省 Token 为目标。
